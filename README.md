# 内耗？no！！！ · 那堵墙

「那堵墙」是一页原创对话页面，围绕深夜舍不得睡、白天缺少属于自己的时间这类情绪做稳定、温和的梳理。页面为单文件静态 HTML，无需后端，对话记录保存在浏览器本地。

## 部署

- 本地直接打开 `index.html` 即可预览
- 线上可部署到 Vercel、GitHub Pages 等任意静态托管
- 本项目未接数据库，所有对话记录仅存在于访问者自己的浏览器中
