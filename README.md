# 内耗？no！！！

不劝你“想开点”，陪你把自己重新看懂。

## 这是什么

《内耗？no！！！》是一组原创“对话页”：把那些反复消耗你的念头，做成一场可以被反复回看的对话。每一页只围绕一种具体的内耗状态展开，不说教、不打鸡血、不下诊断。

目前发布的第一页是**《那堵墙》**
## 怎么用

- 直接说出困扰，页面会以对话的方式回应
- `专业+` / `简单+` 在同一条轴线上调整语言：从“学术深析”到“极简”，内容、意思、逻辑不变，只换说话方式
- 也可以直接说“先安慰我”“先分析再安慰”“说得有条理些”“简短一点”，调整回应的结构
- 对话记录只保存在访问者自己的浏览器里，不上传服务器

## 我们相信

- 内耗不是“想太多”，而是需求与处境在说话
- 情绪可以被接住，也可以被说清楚，两者并不冲突
- 简单不等于降智，专业不等于冷漠
